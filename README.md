# Thiranex Internship Assignments

This repository contains the project submissions for my design internship at Thiranex. The repository is organized into three main design assignments, progressing from structural wireframing to high-fidelity interactive prototypes.

## 📱 Task 1: Mobile App Wireframing
**Objective:** Design low-fidelity wireframes for a mobile application.

**Key Features & Process:**
* Conducted basic user research to define user needs.
* Created user personas and user flows.
* Designed low-fidelity wireframes using Figma or Adobe XD.
* Documented the design thinking process.

**Outcome:** Understand early-stage design planning and user flow creation.

## 💻 Task 2: Website UI Redesign
**Objective:** Redesign the user interface of an existing website to improve usability.

**Key Features & Process:**
* Performed heuristic evaluation to identify usability issues.
* Created mood boards and style guides.
* Designed high-fidelity mockups.
* Ensured responsive layouts for desktop and mobile.

**Outcome:** Gain experience in visual hierarchy, layout design, and responsive design.

## 🚀 Task 3: Interactive Prototype Creation
**Objective:** Build a clickable prototype to simulate real app interactions.

**Key Features & Process:**
* Converted wireframes to interactive prototypes in Figma or InVision.
* Added animations, transitions, and navigation flows.
* Conducted quick user testing on the prototype.
* Gathered feedback and refined designs.

**Outcome:** Learn how to present and test interactive designs effectively.
